


# Unix Commands

## History
- `history` — show all previous commands
- `history | tail -20` — show last 20 commands
- `history | grep <word>` — search command history

## Navigation
- `ls` — list files
- `cd` — change directory
- `pwd` — print current path
- `cat` — print file content

## Process
- `ps aux` — list running processes
- `kill <pid>` — kill process
- `top` — live process monitor

## Network
- `curl` — make HTTP requests
- `ping` — test connection
- `netstat` — network stats

## Files
- `cp` — copy file
- `mv` — move/rename file
- `rm` — delete file
- `find` — search files
- `grep` — search inside files

## System
- `whoami` — current user
- `df -h` — disk usage
- `du -sh` — folder size
- `chmod` — change permissions
