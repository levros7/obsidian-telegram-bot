# Understanding HTTP 500 errors
**Date:** 2026-03-27

---

**🧑 You:** What is it mean error http 500

**🤖 Claude:** **Correction:** "What is it mean" → "What does it mean" — in English questions, we use "does" as the auxiliary verb: "What does [subject] mean?"

---

**HTTP 500 = Internal Server Error**

It means something broke **on the server side**, not on your end. The server encountered an unexpected condition and couldn't complete the request.

**Common causes in your NOC context:**

- Application code crash (unhandled exception)
- Database connection failure
- Misconfigured server or missing dependency
- Timeout from a backend service (e.g., UC4 API, Actimize)
- Out of memory / disk space

**What to check:**

1. Server logs (the actual error is usually there)
2. Recent deployments or config changes
3. Database / backend service health
4. Disk space and memory usage

The key thing: 500 is generic — the real answer is always in the logs.
