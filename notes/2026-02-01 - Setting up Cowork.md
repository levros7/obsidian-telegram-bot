Based on the official documentation, here's how to set up Cowork:

**Basic Requirements:**
- macOS (10.15 Catalina or later)
- Claude Desktop app
- Paid Claude subscription (Pro, Max, Team, or Enterprise)
- 8 GB RAM and 10 GB free disk space

**Setup Steps:**

1. Make sure you have the Claude Desktop app installed and are signed into a paid plan

2. Open Claude Desktop and look for the Cowork tab

3. Select a folder you want to give Cowork access to—this is where it will read and modify files

4. Describe what you want done (e.g., "Organize my Downloads folder" or "Create a spreadsheet from these receipts")

5. Claude will analyze your request, propose a plan, and wait for your approval before executing

6. Once approved, Claude runs the task in an isolated sandboxed environment while you can monitor progress

**Installing Plugins (Optional):**
- Click "Plugins" in the left sidebar
- Browse and install available plugins, or upload custom ones
- Plugins add additional commands you can use with the `/` shortcut

**Important Notes:**
- Cowork consumes more of your usage allocation than regular chat
- It requires an active internet connection throughout the session
- File changes are permanent with no undo, so back up important files first
- It's currently a research preview on macOS only

The key difference from regular Claude: you delegate a complete task and step away, rather than having back-and-forth conversations.
