# Claude Code - Getting Started

## Phase 1: Installation & Setup
- Install Node.js v18+
- Run: npm install -g @anthropic-ai/claude-code
- Connect your API key (from Anthropic Console)
- Initialize in your project folder, type "claude" to begin

## Phase 2: Core Workflow
- Use natural language requests
- Ask Claude to find bugs, write scripts, explain code
- Approve file permissions (y/n) before Claude modifies files
- Create CLAUDE.md file for project-specific instructions

## Essential Terminal Commands
- claude → starts interactive session
- /reset → clears memory, fresh conversation
- /exit → quits Claude Code
