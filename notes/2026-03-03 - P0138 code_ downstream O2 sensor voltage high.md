# P0138 code: downstream O2 sensor voltage high
**Date:** 2026-03-03

---

**🤖 Claude:** **P0138** = O2 sensor (downstream, Bank 1, Sensor 2) reading **too high voltage** — means it's stuck reporting rich, or the sensor itself is faulty.

**Likely causes:**
1. **Faulty O2 sensor** (most common) — replace it
2. **Short to voltage** in the sensor wiring
3. **Rich running engine** (but you'd notice other symptoms)

**What to do:**
- Check wiring/connector first (cheap)
- If OK → replace the downstream O2 sensor (Bank 1, Sensor 2 = after the catalytic converter)

For your Skoda Rapid 2016 this is usually a ~$30–60 part, straightforward DIY replacement.

**🧑 You:** But car is okay

**🤖 Claude:** P0138 can be a **lazy/failing sensor** that hasn't fully died yet — car runs fine because the ECU still manages fuel trim, but the sensor is giving bad readings.

**Options:**
1. **Clear the code** and monitor — if it comes back, the sensor needs replacing
2. **Ignore it for now** — won't cause immediate damage, but could affect fuel economy slightly

It's a confirmed code though, so it will likely return after clearing.
