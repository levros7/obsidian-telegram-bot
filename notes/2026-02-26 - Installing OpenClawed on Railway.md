**Deploy Clawdbot on Railway.app**

1. Go to [railway.app](https://railway.app) → New Project
2. Deploy from GitHub repo (your Clawdbot fork)
3. Set environment variables:
   - `ANTHROPIC_API_KEY` = your Claude API key
   - `TELEGRAM_BOT_TOKEN` = your bot token
4. Deploy → Railway gives you a public URL

**Important:** Clawdbot is designed to run **locally on your own machine** (Mac Mini, Mac, Docker), NOT on Railway. It needs local access to run commands, files, etc.

So you have two options:

**Option A — Run on your Mac** (recommended)
```bash
git clone https://github.com/openclaw/openclaw
cd openclaw && npm install
npm start
```
Then connect Telegram bot token in config.

**Option B — Railway** works but it's limited (no local file access, no Claude Code).
