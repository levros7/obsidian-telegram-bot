# Claude Desktop on iPad compatibility
**Date:** 2026-03-07

---

**🧑 You:** Could I setup Claude dedsktop on ipad

**🤖 Claude:** לא. Claude Desktop לא קיים ל-iPad — רק Mac/Windows.

**האפשרויות שלך ב-iPad:**
- **claude.ai** בדפדפן Safari
- **Claude app** מה-App Store

**🧑 You:** Is there any option

**🤖 Claude:** For Claude Code specifically — no, iPad isn't supported (requires terminal/Node.js).

For general Claude access on iPad, the App Store app is the best option.

**If you want "power user" features on iPad**, the closest thing is claude.ai in Safari with a keyboard — you get most of what Claude Desktop offers except MCP integrations.
