**How to run Claude Code:**

1. Need Node.js 18+ installed
2. In terminal:
```bash
npm install -g @anthropic-ai/claude-code
```
3. Then run:
```bash
claude
```
4. First run asks for your Anthropic API key

That's it. Works in any project folder.
