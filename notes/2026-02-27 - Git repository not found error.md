**🤖 Claude:** This is the **Obsidian Git plugin** error — it can't find a git repo in your vault folder.

**Fix options:**

**Option A — Clone your repo into the vault:**
```bash
cd ~/path/to/your/obsidian-vault
git clone https://github.com/levros7/obsidian-telegram-bot .
```

**Option B — Initialize git in the vault:**
```bash
cd ~/path/to/your/obsidian-vault
git init
git remote add origin https://github.com/levros7/obsidian-telegram-bot
git pull origin main
```
