Исходники: github.com/upstash/context7 2️⃣ Claude-Mem — долгосрочная память Записывает контекст сессий и восстанавливает его в будущих разговорах. Claude работает как senior-разработчик. claude plugin install superpowers Исходники: github.com/obra/superpowers 4️⃣ Security Guidance — автоматическая проверка безопасности Хук от Anthropic. Проверяет каждый edit на уязвимости: XSS, command injection, eval, innerHTML. Блокирует опасный код. claude plugin install security-guidance Источник: официальный маркетплейс Anthropic (github.com/anthropics/claude-plugins-official) 5️⃣ Dev-Browser — браузер для Claude Claude может открыть страницу, проверить UI, кликать на элементы. Реальная проверка вместо слепого написания кода. claude plugin marketplace add sawyerhood/dev-browser claude plugin install dev-browser Исходники: github.com/SawyerHood/dev-browser 🧠 После установки перезапустите Claude Code чтобы плагины активировались.
