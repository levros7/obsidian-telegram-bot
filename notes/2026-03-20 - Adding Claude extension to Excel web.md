**Excel Web בלבד — שלבים:**

1. פתח [office.com](https://office.com) וכנס לקובץ Excel
2. לחץ על טאב **Insert** (הוספה)
3. לחץ **Add-ins**
4. חפש **"Claude by Anthropic"**
5. לחץ **Add** → התחבר עם חשבון Claude שלך

התוסף תואם ל-Excel on the web — אין צורך בהתקנה נפרדת.

לצערי, **Claude for Excel לא זמין ב-Excel Web** כרגע — התוסף עובד רק על:

- Excel Desktop (Windows / Mac) עם Microsoft 365

זו מגבלה של Microsoft, לא של Anthropic. אין דרך לעקוף את זה ב-Excel Web כרגע.

**האופציה היחידה:** להשתמש ב-Excel Desktop ולהתקין את התוסף שם.
